# Audits

> **Current** index, kept up to date. Every folder it lists is a historical record: its documents say so at their top, and describe the tool as it was on their date. For where things stand now, read the [README](../../README.md).

Every review of the tool or its database lives here, one folder each, named
`<date>-<subject>`. A folder holds the report exactly as it was delivered (`REPORT.md`) and what was
done about it (`RESPONSE.md`), plus any evidence files the reviewer supplied, in lower-case
kebab-case names.

Where an audit changed the data, its folder holds a changelog of what moved and the script that made
the edit. Until 2026-09-14 those edits patched the Excel workbook and refused to run on any workbook
but the one they were written against; those scripts are history and no longer run. Since then an edit
goes through `scripts/data/table-io.mjs` with expected-value guards, and its changelog is generated by
`npm run data:diff`.

A report is a record of what someone found on its date, not a description of the tool today. Read
the response beside it for what changed.
