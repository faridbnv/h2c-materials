## What the M3-close review found, and what the follow-up PR does

1. **Blocking: the preview served the old build's material pages.** The root's `materials/` was a copy of `dist/materials`, so the TypeScript pages never reached the site. Now the view build renders `packages/pages` from the same new-build database its data parts are cut from, into the root's `materials/`; `dist/materials` stays at `legacy/materials/` only. The browser suite and the size report run on that layout.
2. **The release ID left out inputs that decide what the parts hold** (also M2 open item WP20-D1): `packages/build/src`, the data code that reconstructs the tables, `apps/public/src/view-fields.ts`, `view-facts.ts`, `model.ts` and `packages/pages/src/facts/dates.ts`. They are inputs now, and a test walks the import graph of the parts writer and fails on any file it reaches that is neither an input nor named as deciding nothing.
3. **An export or brief on a stale page said "check the connection".** A gone part now reloads the page once, keeping the address, and then says the page is older than the data.
4. **The owner's 2026-10-22 decisions are recorded** in `docs/next/rulings.csv` (below).
5. **The preview smoke only counted verdicts.** It now also checks `shared.json` and one `detail/<id>.json` of the current release, and asks the engine two real questions (Strict, and Explore with estimates) of the parts it fetched. The smoke job installs the workspace packages (no scripts) for that.
6. **"Counted once in the median" was printed on every shared-sheet value**, including values the median does not count (a variant's, a value set apart): 44 such values on 14 pages. The build and the pages now share one rule (`isReprintEntry`, `packages/domain`), and the wording appears only where the median leaves the reprint out. The pages-display transition was re-emitted (below).
7. **A stale skip allowance** ("new selector: Ashby decision workspace") is gone, and the browser runner now fails on an allowance no skipped check used.
8. **Status files and this record** are brought to the real state.
